Contact and feedback
========================

Questions, bug reports and feature suggestions are welcome.

Reporting issues
------------------------

Use `GitHub Issues <https://github.com/lyushisyan/NEP-kappa/issues>`_ to report
problems so that discussions and progress can be tracked.

When reporting an issue, please include:

* Your NEP-kappa version, Python version and operating system.
* The command you ran, the calculation backend and relevant external-program versions.
* A minimal reproducible YAML input and the necessary structure and model information.
* The expected result, the actual result and relevant errors from ``run.log``.

Check software versions with:

.. code-block:: bash

   nepkappa --version
   python --version
