TD-BTE 碰撞核验证
================================

当前结论
------------------------

2026-11-07 的独立审计通过离散数值不变量与匹配求积的散射前因子对照，但没有完成生产核绝对速率验证。
小 q 离壳声学端点差异是辅助诊断，不能单独判定在壳动力学失败。
该检查现为可选，不阻止 :doc:`tdbte_spatial` 的软件开发。
均匀积分方法和物理碰撞系数没有为迎合审计结果而修改。

本地审计脚本为 ``tools/validate_tdbte_kernel.py``，输出带哈希的核、按模式排序的速率与 JSON。
``tools/`` 被 Git 忽略，新克隆不分发它。公开测试在缺少脚本时跳过对应的可选审计检查。

线宽、寿命与归一化
------------------------

phono3py 的 ``gamma`` 是虚部自能 / 半线宽，使用普通频率 THz。
正值对应的占据数寿命倒数为：

.. math::

   \tau_\lambda^{-1}\ [\mathrm{ps}^{-1}]
   = 2(2\pi)\,\mathrm{gamma}_\lambda\ [\mathrm{THz}].

因子 2 来自半线宽与占据数寿命的区别，2π 来自普通频率与角频率的区别。
生产事件系数采用：

.. math::

   c_e = 4\pi U S_e w_e^{\mathrm{surface}}.

原生相互作用强度已含 ``1/Nq``，不能在碰撞积分中再乘一次。
报告能量中的独立 ``1/Nq`` 是布里渊区平均。保留有序子模式，不添加额外拟合尺度或子模式倍数。
审计按网格地址和原生映射验证模式排序，不能靠频率匹配模式。
原生 ``q0+q1+q2=G`` 约定对应衰变母模式 ``qp=-q0``。

需区分三种速率量：

* 标记腿线宽：其他腿固定，重复子模式按各个标记出现次数分别计数。
* 占据数 Jacobian 对角元：先合并同一模式在事件中的所有出现，再求导；重复子模式会产生交叉项。
  插值和沉积权重也参与，不能直接当作原生线宽。
* 母模式衰变损失系数：只取 ``p ↔ b+c`` 的母腿贡献，即对事件求和 ``c_e(1+n_b+n_c)``。
  独立原生对照是 class-2 衰变项乘 4π；这只验证一个可识别通道。

匹配 Gaussian 求积的对照使用相同 FC、网格、温度、sigma、截断和常数，独立调用 ``ImagSelfEnergy``。
这些 Gaussian 事件只用于前因子诊断，不替代生产能量壳事件进行传播。
生产求解器使用 SciPy 常数，原生后端使用自己的常数；报告保留差异，避免以调常数掩盖模型差异。

数值检查能证明什么
------------------------

熵插值弱离散算子的导数可写为：

.. math::

   J=-BRB^T D^{-1},\qquad D_\lambda=n_\lambda(1+n_\lambda).

审计组合重复模式索引，分块装配作用，并与实际非线性 RHS 的中心差分比较。
还检查 100、300、1000 K 的 Bose 平衡、不同幅值的正非平衡初态、能量守恒、熵产生以及多腿有限幅响应。
这些性质在给所有事件乘同一错误常数时也可能成立，因此不能证明绝对时间尺度正确。

曲面积分收敛通过把现有二次曲面三角形细分为四个，并重建同一线性强度和重心插值来检查。
跨磁盘块的三角形会重新组合。它只隔离曲面积分误差，不加密声子网格，也不改进支跟踪或端点模型。

声学端点诊断
------------------------

三维 Gamma 的三个刚性平移被固定为零频、零熵变量和零顶角。
小 q 检查在非 Gamma 三元组上直接计算原生 Fourier / 简正模顶角，先与原生网格三元组的分支求和强度比较，
再检查两个软 q 方向和六种腿置换。对简并子空间求支和可减少任意规范的影响。
不为该检查修改或对称化原始力常数。

被采样量不含能量 delta 和 Bose 因子，是离壳顶角强度，不是散射率。
它随小 q 增大，不足以证明在壳线宽发散或稳态输运错误；
但说明采样原生顶角不能支持生产插值中的零端点假设，仍需研究其实际在壳权重。

复现命令与来源
------------------------

需要本地脚本及一组已有配套 FC，输出目录必须不存在：

.. code-block:: bash

   OMP_NUM_THREADS=1 RAYON_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 \
     python tools/validate_tdbte_kernel.py \
     --source calculations/3C-SiC/manual-stages \
     --output calculations/3C-SiC/tdbte-validation-reproduction \
     --meshes 2 3 4 --surface-levels 0 1 --acoustic-check

此命令不生成原子力。它在运算前后核对三份 FC / 元数据文件哈希，模式速率写入 ``mesh-N/rates.npz``。
去掉 ``--acoustic-check`` 可省略离壳诊断。当前不完整物理验收会使工具返回退出码 1，
并记录 ``stage_1_acceptance_passed: false``，不能与软件回归测试失败混为一谈。

历史来源是弛豫后的两原子 3C-SiC、专用 NEP、3×3×3 FC 超胞且无 NAC。
它不是公共仓库的数据。其他 FC 数据或用示例的未弛豫结构重新生成 FC，都是新的基准来源，数值不应强求一致。
来源哈希和详细结果保存在
:download:`原始验证 JSON <../source/_static/tdbte-validation-20261107.json>`。

------------------------

生产比较采用不同积分方案，差异不能解释为应当施加的修正因子。
例如 Gamma 光学母衰变系数随网格变化为 0.24827、0.50178、0.54936 ps⁻¹，
相应原生值为 0.21230、0.47695、0.53378 ps⁻¹；这些粗网格不能证明绝对速率收敛。
Jacobian 作用的中心差分误差约达 3e-11；平衡、能量和熵检查通过。

使用 3×3×3 核、300 K、3–5 支 1% 激发的 0.1 ps 均匀短算例，也通过正性、平衡和能量 / 熵审计。
这是数值冒烟检查，不是时间步或物理速率收敛。
小 q 顶角在采样方向的对数斜率约为 -0.996 和 -0.995；置换与原生网格对照一致，
但仍不能据此断言在壳速率的极限性质。

后续物理验收
------------------------

需建立完整标记速率 / 算子的独立基准，并检查 q 网格、曲面、力常数超胞和声学在壳通道的收敛。
不应通过重标度系数、删除声学事件、禁用平均或修改来源 FC 来强行获得一致。
匹配 Gaussian 前因子或单个衰变通道的一致性不足以替代这项工作。
