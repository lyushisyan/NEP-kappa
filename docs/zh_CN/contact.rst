联系与反馈
========================

欢迎反馈使用问题、程序错误和功能建议。

问题反馈
------------------------

建议通过 `GitHub Issues <https://github.com/lyushisyan/NEP-kappa/issues>`_
提交问题，便于记录讨论和跟踪处理进展。

反馈时请尽量提供：

* NEP-kappa 版本、Python 版本和操作系统。
* 实际运行的命令、使用的计算后端和相关外部程序版本。
* 能复现问题的最小 YAML 输入，以及必要的结构和模型信息。
* 预期结果、实际结果，以及 ``run.log`` 中的相关报错。

可用以下命令查看版本：

.. code-block:: bash

   nepkappa --version
   python --version
